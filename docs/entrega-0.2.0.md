# PEA-i 0.2.0 · Parcial 2

Esta entrega incorpora el indicador científico para grupos e investigadores,
169 categorías del Modelo original, puntajes por producto, desglose de los nueve
componentes, referencias de normalización y avisos de datos insuficientes.

Incluye trabajo con catálogos JSON locales, inicio sin datos, edición
complementaria, procesamiento PDF C++ con Poppler y comparación real de las
salidas Python/C++. Conserva las estructuras propias, la integración Supabase y
el historial de correcciones de persistencia.

La guía [Parcial 2](parcial-2.md) explica las fórmulas, la diferencia entre
referencia local y nacional, los comandos y la trazabilidad del enunciado.
La especificación Word, UML y video no forman parte del alcance solicitado.

El ZIP portable incluye ambas aplicaciones, dependencias, licencias, configuración
pública, identificación, entradas académicas y un catálogo sintético guardable.
`VERSION-ENTREGA.json` identifica el commit y la versión; `SHA256SUMS.txt` permite
comprobar los archivos publicados. La Release se publica después de comprobar
el artefacto generado por GitHub Actions en Windows.
